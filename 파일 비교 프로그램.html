파일 비교 툴 v18 (TEXT IF 지원 / 오프라인 / 탭별 엑셀 다운로드)

- 값 컬럼이 키 컬럼과 동일(예: 키=예약코드, 값=예약코드)하면 TEXT(IF) 모드로 자동 전환됩니다.
- TEXT(IF): IF(baseVal == targetVal, "일치", "불일치") (누락은 별도)
- XLSX는 브라우저가 DecompressionStream을 지원해야 압축 해제가 가능합니다. CSV는 항상 가능.
1. 파일업로드 대기
시트 선택(파일별) -
XLSX만 시트 선택 가능. CSV는 시트 없음.
불러오기 전입니다.
2. 비교대상 미설정
파일명은 선택(옵션)입니다. 선택하지 않으면 업로드된 파일 전체로 자동 비교합니다. “추가”를 누르면 키/값 드롭다운이 계속 생성됩니다.
포함 필터 (선택한 컬럼에서 특정값만 비교)
필터는 AND로 적용됩니다. 포함값은 쉼표(,)로 여러 개 입력 가능.
baseKeyset: Base(A)에서 필터 통과한 “키”만 B/C 비교 대상으로 포함
적용중 필터
-
선택된 키/값(요약)
- 값 컬럼이 키와 같으면 TEXT(IF) 모드로 자동 전환됩니다.
Base 기준: (1) 비교대상에서 첫 번째 선택된 파일이 Base, (2) 선택이 없으면 업로드된 첫 파일이 Base.
결과 -
1) 일치
2) 불일치
3) 누락
4) 상세
